# --- GPU support for faster-whisper (CTranslate2 backend) ---------------------------------
# ctranslate2 (faster-whisper's backend) is pulled in automatically as a faster-whisper
# dependency, but its Windows wheel dynamically links against CUDA *12*'s cublas64_12.dll
# specifically, regardless of what CUDA Toolkit version is actually installed on the machine.
# If your CUDA Toolkit is 12.x and its bin/ is on PATH, you may already have this and can
# skip the two lines below. On this dev machine the installed Toolkit is CUDA 13.3 (needed
# for Phase 1's rwkv.cpp CUDA build), which does NOT ship cublas64_12.dll -- so
# faster-whisper's device="cuda" would fail at first inference with "Library
# cublas64_12.dll is not found or cannot be loaded" without these redistributable packages,
# which vendor the actual CUDA 12 DLLs faster-whisper needs, independent of the system
# Toolkit version. See voice-pipeline/stt.py's _ensure_cuda12_dlls() and the README's
# "GPU/CPU device placement" section for the full story.
nvidia-cublas-cu12==12.9.2.10
nvidia-cudnn-cu12==9.24.0.43
